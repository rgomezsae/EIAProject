# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email the maintainer directly or use GitHub's private
vulnerability reporting feature:

1. Go to the **Security** tab of this repository on GitHub
2. Click **"Report a vulnerability"**
3. Provide a description of the issue and steps to reproduce it

## What to Expect

- You will receive an acknowledgment within 48 hours
- The maintainer will investigate and work on a fix
- You will be credited for the discovery (unless you prefer to remain anonymous)

## Scope

This policy applies to the code in this repository. If you find a
vulnerability in a third-party dependency, please report it to the
maintainers of that dependency as well.
